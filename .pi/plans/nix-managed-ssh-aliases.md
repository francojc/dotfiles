# Nix-Managed SSH Alias Fragment Plan

## Goal

Generate stable SSH aliases from Home Manager without letting Nix own or replace `~/.ssh/config`.

Keep `~/.ssh/config` as mutable dispatcher for OrbStack and other applications. Add one explicit include for a Home Manager-generated fragment:

```sshconfig
# ~/.ssh/config
Include ~/.orbstack/ssh/config
Include ~/.ssh/config.d/nix-managed.conf
```

OrbStack include remains first. Its generated `orb` host requires first position before all `Host` blocks.

## Current aliases to migrate

Move current static host entries into generated `nix-managed.conf`.

| SSH alias | Generated `HostName` | User | Port | Key |
|---|---|---:|---:|---|
| `forgejo` | `forgejo` | `forgejo` | default | `~/.ssh/id_ed25519_forgejo` |
| `codeberg.org` | default, same as alias | `git` | default | `~/.ssh/id_ed25519_codeberg` |
| `rover` | `mini-rover` | `jeridf` | `22` | SSH defaults |
| `minicore` | `mac-minicore` | `jeridf` | `22` | SSH defaults |
| `airborne` | `macbook-airborne` | `francojc` | `22` | SSH defaults |

Notes:

- `forgejo` replaces existing `forgejo.gerbil-matrix.ts.net` alias and hostname. Tailscale MagicDNS resolves `forgejo`, so public configuration need not expose tailnet domain.
- `codeberg.org` remains unchanged because it is public service hostname and likely used by existing Git remotes.
- `rover`, `minicore`, and `airborne` use existing MagicDNS-style host names.
- Private key contents remain outside Nix and Git. `IdentityFile` paths only reference existing local keys.
- Current comments added by LazySSH do not move into generated config. Alias behavior moves; application provenance does not.

## Intended ownership

```text
~/.ssh/config                         user/app-managed dispatcher
~/.orbstack/ssh/config                OrbStack-managed dynamic fragment
~/.ssh/config.d/nix-managed.conf      Home Manager-generated static aliases
```

Avoid wildcard include such as `Include ~/.ssh/config.d/*`. Explicit include gives known precedence and prevents arbitrary app-created fragments from changing SSH behavior.

## Phase 2 – add Home Manager module

Create shared module:

```text
.config/nix/home/ssh-aliases.nix
```

Add it to imports in:

```text
.config/nix/home/default.nix
```

Module responsibilities:

1. Use `home.file.".ssh/config.d/nix-managed.conf".text` to generate only include fragment.
2. Render migrated aliases in stable order.
3. Do not set `programs.ssh.enable` or otherwise manage `~/.ssh/config`.
4. Keep key contents out of Nix expressions.
5. Add a short comment marking fragment generated by Home Manager.

Target fragment:

```sshconfig
# Generated by Home Manager. Do not edit directly.

Host forgejo
  HostName forgejo
  User forgejo
  IdentityFile ~/.ssh/id_ed25519_forgejo
  IdentitiesOnly yes

Host codeberg.org
  User git
  IdentityFile ~/.ssh/id_ed25519_codeberg
  IdentitiesOnly yes

Host rover
  HostName mini-rover
  User jeridf
  Port 22

Host minicore
  HostName mac-minicore
  User jeridf
  Port 22

Host airborne
  HostName macbook-airborne
  User francojc
  Port 22
```

Checks:

- [ ] Generated file contains no secret material.
- [ ] Nix formatter passes.
- [ ] File generation does not replace main `~/.ssh/config`.
- [ ] Home Manager creates parent directory as needed.

Exit: Home Manager produces static alias fragment from tracked source.

## Phase 3 – add dispatcher include safely

One-time manual change to existing `~/.ssh/config`:

```sshconfig
Include ~/.orbstack/ssh/config
Include ~/.ssh/config.d/nix-managed.conf
```

Place Nix include immediately after OrbStack include and before other host entries.

Then remove migrated static `Host` blocks from `~/.ssh/config`:

- `forgejo.gerbil-matrix.ts.net`
- `codeberg.org`
- `rover`
- `minicore`
- `airborne`

Keep unrelated app-managed entries intact.

Ordering rationale:

- SSH generally uses first obtained value for a setting.
- OrbStack remains first as required by its own generated config.
- Nix aliases become authoritative for their exact `Host` names.
- Later application entries under different aliases remain normal.

Checks:

- [ ] Main config contains one OrbStack include and one Nix fragment include.
- [ ] No duplicate migrated `Host` blocks remain in main config.
- [ ] `ssh -G` output matches baseline except intentional Forgejo alias/hostname change.
- [ ] `ssh forgejo` reaches Forgejo.
- [ ] `ssh rover` reaches Rover.

Exit: SSH resolves all migrated aliases through Nix-generated fragment.

## Rollback

1. Remove or comment `Include ~/.ssh/config.d/nix-managed.conf` from main config.
2. Restore static host blocks from Git history or this plan.
3. Rebuild without `ssh-aliases.nix` import if required.

No private keys, remote services, or session files are modified by this migration.
